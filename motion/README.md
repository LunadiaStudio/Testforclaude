# 인트로 모션그래픽 (네온 → 다음 게임)

| 파일 | 내레이션 | 길이 |
|---|---|---|
| `out/scene1.mp4` | 지난달, 저는 발로란트의 요원 네온을 마인크래프트로 구현해봤습니다. | 5.5s |
| `out/scene2.mp4` | 그 영상의 반응은 그야말로 엄청나게 뜨거웠는데요. | 5.5s |
| `out/scene3.mp4` | 그래서 저는 이 기세를 이어서 이번에는 옆동네의 게임도 마인크래프트로 만들어보기로 했습니다. | 7.0s |

1920×1080, 30fps, H.264.

## 수정하기
- 제목, 조회수, 좋아요 같은 값은 `index.html` 맨 위의 `CONFIG`에서 바꿔요.
- 타이밍은 각 `sceneN()` 함수 안의 초 단위 숫자를 고치면 돼요.
- 브라우저에서 `index.html?scene=2`를 열면 실시간으로 미리 볼 수 있어요.

## 렌더링
```
node render.mjs        # 전체
node render.mjs 2      # 씬 2만
```
Playwright(Chromium)와 ffmpeg가 필요해요. 폰트는 Pretendard(OFL)를 써요.
